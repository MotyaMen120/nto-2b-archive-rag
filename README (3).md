# Данные 2Б «Спроси архив»

Набор содержит 1 200 вопросов: 800 в train и 400 в test (200 в публичной части, 200 в приватной). Условие и метрика описаны в описании кейса.

## Файлы

- corpus.parquet: 142 226 постов за 2024-01-01 — 2026-03-10; колонки post_id, date, channel, channel_type, text. В evidence указывается post_id.
- train.csv: 800 вопросов с ответами (answer) и доказательствами (evidence). В evidence перечислены через пробел все найденные посты, из которых следует ответ, поэтому их может быть больше пяти. В сабмите допускается не больше пяти.
- test.csv: 400 вопросов без ответов и без колонки level (уровень сложности есть только в train). Каждая история целиком лежит либо в train, либо в test.
- train_groups.csv: группа каждого вопроса train (qid, group; 382 группы). Вопросы разных групп не делят ни истории, ни посты-доказательства, поэтому валидацию на train делите по group: каждая группа целиком в одной части.
- sample_submission.csv: пример файла сдачи с ответом skip для каждого вопроса test.
- examples.csv и examples_gold.jsonl: 51 ознакомительный пример. Это те же строки train (qid начинается с seed-), отдельно к общему числу они не добавляются.
- submission.py: строгая проверка файла сдачи: все qid ровно один раз, допустимые ответы, существующие post_id, не больше пяти доказательств.
- score.py: локальный расчёт метрики. По умолчанию эталоном служит train.csv; удобно для валидации на отложенной части train.
- units.py: словарь обозначений единиц в колонке unit.
- requirements.txt: зависимости ноутбука. PyTorch с CUDA устанавливается отдельно для вашей платформы; в Colab он уже есть.

## Запуск бейзлайна

Рядом с baseline.ipynb должна лежать папка data с этими файлами. В Colab подключите Drive и задайте ROOT. Зависимости и закреплённые веса скачиваются заранее, с сетью; поиск и ответы потом работают локально.

Ноутбук отвечает на весь test и сохраняет output/submission.csv после строгой проверки. Если задать RUN_TEST = False, он отвечает на первые DEMO_LIMIT вопросов train и считает по ним балл через score.py.

Проверка сдачи:

    python data/submission.py output/submission.csv --questions data/test.csv --corpus data/corpus.parquet

Локальный балл на части train (предсказания в том же CSV-формате):

    python data/score.py my_train_predictions.csv --gold data/train.csv --subset
