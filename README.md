# НТО ИИ 2026/27 — Кейс 2B «Спроси архив»

Офлайн temporal RAG по архиву городских сообществ Нижегородской области.
Корпус: 142 226 постов; train: 800 вопросов; test: 400 вопросов.

## Реализация

- BM25 + E5/BGE MaxP + RRF с фильтром `post_date <= asked_at` до скоринга.
- Словарь перифраз, дополнительные запросы для хронологии, cross-encoder.
- Локальная Qwen2.5-7B NF4 с JSON-выводом и Python-калькулятором.
- Обработка репостов, LightGBM LambdaRank для evidence, вложенная GroupKFold-калибровка.
- Контроль памяти, `float16 memmap`, промежуточные кэши и возобновление генерации.
- Официальная проверка каждого итогового CSV.

Подробности и отдельные команды: [README_2b_v2.txt](README_2b_v2.txt).
Условие кейса: [кейс.md](кейс.md). Правила проекта: [AGENTS.md](AGENTS.md).

## Запуск

Требуются Python 3.12, CUDA PyTorch и заранее подготовленные локальные веса.
Проверенное окружение: PyTorch 2.6.0+cu124; зависимости перечислены в
[requirements_2b_v2.txt](requirements_2b_v2.txt).

```powershell
py -3.12 -m pip install -r requirements_2b_v2.txt
py -3.12 -X utf8 solution_2b_v2.py --mode smoke
```

Подготовка E5-large и BGE-реранкера с сетью, до инференса:

```powershell
py -3.12 -X utf8 prepare_weights_2b.py
```

Reader `Qwen/Qwen2.5-7B-Instruct` тоже должен быть заранее доступен в локальном
HF-кэше. Можно указать его локальную папку через `--reader`.

Полный офлайн-прогон:

```powershell
py -3.12 -X utf8 run_complete_2b.py
```

Результат после успешного завершения: `output_2b_final/submission.csv`, OOF-отчёт,
обученные мета-реранкер и калибратор, `completion.json` и архив решения.
Имена входных файлов с суффиксами скачивания, включая `train_groups (1).csv`,
определяются автоматически. Доступны явные `--corpus`, `--train`, `--test`,
`--groups`, `--output`.

## Что проверено

- 21 регрессионный тест, включая временной барьер, вложенные фолды, расчёты,
  checkpoint и эквивалентность attention при обработке блоками.
- Настоящие 382 группы: пять фолдов по 160 вопросов, без общих золотых постов.
- Локальная Qwen2.5-7B NF4 на десяти реальных вопросах: пик 6,79 GiB VRAM
  и 3,42 GiB RAM на RTX 3070 Ti Laptop. Это профиль ресурсов, без оценки S.
- OOF-проверка ранжирования evidence на BM25: средний AP@5 вырос с 0,398
  до 0,502 после LightGBM; взвешенный — с 0,328 до 0,425. Вопросы с пустым
  золотым evidence исключены из этих средних. Это оценка evidence, а не общий S.

Отчёты: [ранжирование BM25](output_2b_final/lexical_ranker_baseline/report.json),
[профиль reader](output_2b_final/reader_profile/result.json),
[диагностика поиска](output_2b_v2/retrieval.report.json).

**Полный OOF/test-прогон и итоговый сабмит пока не получены.**
Запуск на T4 и лимит шесть часов ещё не подтверждены на целевом оборудовании.
Веса, кэши и незаконченные загрузки исключены из Git; данные кейса включены.

В поставленном `score (2).py` AP@5 для `skip` обнуляется. Код сохраняет evidence
согласно правилам проекта, а калибратор использует фактическую официальную метрику.
