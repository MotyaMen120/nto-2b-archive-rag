# Codex Error Debugger — Диагностика багов и анализ ошибок

## Когда вызывать
- При любом исключении, OOM, несоответствии формата в `submission.py` или необъяснимой просадке OOF.
- Перед планированием следующей итерации улучшений (чтобы бить в реальное узкое место, а не в догадки).

## Протокол отладки кода (баги и падения)
1. **Минимальное воспроизведение**:
   - Изолируй падение на 1–5 конкретных `qid` (не перезапускай полный прогон на 800 вопросов ради отладки одной ошибки).
2. **Проверка 5 главных источников скрытых багов в кейсе 2B**:
   - *Утечка будущего*: `post_date > asked_at` в `evidence` или контексте LLM.
   - *Типы дат*: сравнение `str` с `datetime.date` / `pd.Timestamp` (разные форматы `YYYY-MM-DD` vs timestamp).
   - *Индексы `post_id` vs позиционный индекс массива*: перепутаны `df.iloc[i]` и `post_id` после фильтрации/сортировки корпуса!
   - *Парсинг JSON / чисел*: запятая вместо точки (`40,5` → `40.5`), пробелы в тысячах (`12 000` → `12000`), единицы измерения не переведены по `units.py`.
   - *Пустой `evidence` при `skip`*: потеря `0.3 * AP@5`, или непустой `evidence` при `no_info`.

## Протокол ML-анализа ошибок (Error Slicing)
Для OOF-предсказаний сформируй отчёт, разбивая каждую ошибку по 4 причинам:
1. **Retrieval miss**: нужные золотые посты не вошли в топ-100 кандидатов (проблема перифразов, 2-hop, BM25/dense).
2. **Rerank / Context miss**: посты были в топ-100, но не попали в контекст LLM или топ-5 `evidence`.
3. **Reasoning / Math error**: посты были в контексте LLM, но неверный вывод (разница дат, исторический статус, ложная предпосылка в `choice`).
4. **Abstention / Format error**: неверный `promised`/`no_info`/`skip` или единица измерения.

Выводи **топ-15 самых дорогих ошибок** по формуле `loss_q = w_q * (1.0 - s_q)` с полями: `qid`, `level`, `answer_format`, `asked_at`, `gold`, `pred`, `gold_in_top100`, `gold_in_context`, `gold_in_top5`.

## Регрессионная проверка
После фикса бага добавь проверку (unit-тест или assert-скрипт), покрывающую найденный класс ошибок и прогоняющуюся на `examples_gold (2).jsonl` за секунды.
